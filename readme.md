# Diesel Sentry

Android application for monitoring Diesel vehicles.

## Latest Release

**Version:** v3.0.10
**Download:** [AutoSentry-v3.0.10.apk](https://drive.google.com/file/d/1r207ZDXp7lPkwXeNxYWqObEJKY2pnzua/view?usp=drive_link)

## Installation

1. Download the APK file from the link above
2. Enable "Install from Unknown Sources" in Android Settings
3. Open the downloaded APK file
4. Tap "Install" when prompted

## Requirements
- Android 5.0+ 
- Diesel vehicle OBD-II port access
- Compatible adapter (ELM327 or equivalent)

## Features
- Real-time engine diagnostics
- Fuel consumption tracking
- Maintenance alerts
- Fault code scanner
